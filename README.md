## 行级编辑与实时预览

![Mote 行级编辑和文件内嵌预览示意](docs/inline-preview.svg)

Mote 有清晰的阅读、编辑两种模式：

- 笔记文件名就是标题；顶部标题与 Markdown 正文是两个独立编辑区域。
- 在编辑模式下可直接修改标题，修改后会同步重命名笔记；正文行首退格不会删入标题。
- 旧版本自动写入正文的同名 `# 标题` 会在首次打开时一次性分离，不会与文件名重复。
- 阅读模式没有光标，所有行都是渲染结果。
- 阅读模式使用触摸级双击识别；第一次双击预览内容就会直接进入对应 Markdown 行编辑，不依赖可能被文本选择吞掉的 click 事件。
- 编辑模式只有光标所在行显示 Markdown 源码，其他行继续显示渲染结果。
- 正文编辑时，输入法上方会显示可横向滚动的 Material Markdown 工具栏：标题菜单支持正文与 H1–H6，并提供加粗、斜体、删除线、任务项、无序/有序列表、引用、行内代码和 Markdown 链接。
- 撤回和重做位于仅在编辑时显示的 Markdown 工具栏，不再挤占顶部标题区。500ms 内同一行的连续输入或连续删除会合并为一步；换行、格式化、粘贴和附件操作各自独立成步，最多保留 100 步。物理键盘同时支持 `Ctrl+Z`、`Ctrl+Shift+Z` 和 `Ctrl+Y`。
- 快捷格式支持当前选区：加粗、斜体、删除线和代码会包裹或取消包裹所选内容；没有选区时会插入成对标记并把光标放到中间。列表、任务项、引用与标题会替换当前行已有的块级前缀，避免产生叠加错误。
- 编辑器会自动补全 `[]`、`()`、`{}`、反引号和英文双引号：光标停在中间，输入已有闭合符时直接越过；选中文字后输入左符号会包裹选区，空配对中按退格会同时删除两侧。软键盘与物理键盘使用同一套规则。
- 点击另一行会直接移动编辑位置，不需要点击“完成”。
- 阅读模式和编辑行都使用 Android 原生文本选择；编辑行长按不会再被附件粘贴逻辑抢占，可拖动选择手柄并使用系统提供的剪切、复制、粘贴和全选。
- 在当前行按回车会拆分并进入下一行；有序列表会自动续写下一编号。编辑器比较编号前缀的前后状态，因此在连续同级编号项之间插入、删除后重新加回编号、替换数字或改变缩进时都会按上下文重排，同时保留有意设置的起始编号和不同缩进层级。
- 在行首按退格会合并到上一行，刚换行后可立即退回上一行。
- 右上角的书写/阅读图标切换模式，链接形状的图标统一负责插入文件。
- 图标、状态栏和编辑界面跟随系统明亮/深色主题；亮色界面使用纯白背景，暗色界面使用纯黑背景，并采用 Google Material 蓝色强调色。
- 编辑源码会按屏幕宽度自动折行；回车仍会创建下一条 Markdown 源码行。
- 输入法弹出、切换编辑行或当前行自动折行时，正在编辑的行会自动保持在键盘上方。
- 编辑模式按返回键会先回到无光标的阅读预览，再按一次才退出笔记返回目录；输入法显示时也遵循相同行为。
- 提供 Adaptive Launcher 图标和 Android 13+ 单色主题图标。
- 普通 Launcher 图标保留原来的浅色笔记页、淡蓝书脊和橙色书写笔，并将整体视觉重心向右微调；亮色背景为白色，暗色背景为黑色，暗色笔记页单独提高明度以避免与黑色背景融为一体。

## 笔记库与文件夹

应用启动后首先进入笔记库，而不是直接打开固定笔记：

- 右上角分别提供“新建文件夹”和“新建笔记”。
- 文件夹可以嵌套，工具栏显示当前位置并提供返回上级按钮。
- 文件夹始终排在笔记前面；点击文件夹进入，点击笔记打开编辑器。
- 笔记与文件夹可以使用相同显示名称；同类型重名会从 `名称 (1)` 开始编号，不会覆盖已有内容。
- 点击笔记右侧的更多按钮或长按笔记，可以选择目标文件夹移动笔记；Markdown 与 assets 会整体移动。
- 笔记和文件夹的删除操作会将完整内容（包括附件与嵌套目录）移入回收站，不再立即永久删除。
- 回收站支持恢复与永久删除；自动清理时间可选 7、30 或 90 天，默认保留 30 天。恢复时优先回到原目录，重名则使用 `(1)` 等安全的新名称。
- 文件夹支持移动，嵌套层级与内部笔记、附件会整体保留；不能移动到自身或自己的子文件夹。
- 笔记和文件夹均支持重命名，附件与子目录会原样保留；同类型重名会明确提示而不会覆盖。
- 新建文件夹和笔记使用 Material 轮廓输入框，标签、边框与输入文字互不重叠。
- 旧版本的 `welcome` 笔记会自动出现在根目录，不迁移、不删除原数据。
- 目录路径经过规范化检查，不能通过名称越过笔记库目录。

## 主题与主页外观

主页左上角的三横线入口始终打开 Material 侧边栏，进入子文件夹后也不会被返回按钮替换；外观与布局、WebDAV、插件管理和回收站都集中在侧边栏：

- 内置 Mote、Catppuccin、Tokyo Night 与 Obsidian Minimal 风格主题。主题选择器使用每套主题自己的强调色名称和三色预览，不再显示成统一的灰色文字列表。各页面标题栏与正文使用完全相同的主题背景，不再额外增加灰色工具栏色块；Catppuccin 使用 Latte/Mocha 官方色阶，Tokyo Night 使用其官方昼夜前景、背景与蓝色强调色，Minimal 保持可定制主题的中性低干扰层级。
- Samsung 风格默认将文件夹以双列卡片置于上方，笔记在下方保持易扫读的列表；也可切换为紧凑列表或双列缩略图网格。
- 笔记预览分为三种独立模式：“第一页渲染预览”会生成包含标题、Markdown 样式、图片和 PDF 首页的页面缩小图；“正文摘要”只显示可扫读的文本摘要；“仅显示标题”用于最紧凑的目录。
- 页面缩略图在后台生成并按笔记修改时间、主题和尺寸缓存，不阻塞目录滚动；旧版“首页图片与摘要”设置会自动迁移到第一页渲染预览。
- 文件夹菜单提供 12 种 Material 风格颜色。色板使用主题化圆角表面、圆形色芯、选中描边、勾选与波纹反馈，不显示冗余颜色文字；实际色值会随 Mote、Catppuccin、Tokyo Night、Minimal 以及系统明暗模式切换，保存的颜色语义与元数据会随文件夹重命名、移动、回收和恢复一起保留。
- 文件夹与笔记分区标题、项目计数、圆角卡片、主题化空状态和统一间距让大目录仍然保持清晰层次。

## 文件插入

插入按钮使用 Android 系统文件选择器，并根据所选文件自动处理：

- 图片直接显示。
- PDF 展开为真实页面，页面在接近屏幕时才渲染。
- PDF 每一页都可以独立展开或收起；首页标题栏右侧的整份折叠按钮会一次隐藏全部页面及其页间笔记，再次展开时会恢复各页此前的独立折叠状态。同一个文件插入多次仍互不影响。
- 编辑模式下每一页下方都有“在本页后添加笔记”入口。页间内容仍是普通 Markdown 行，可使用现有工具栏、实时预览、撤回/重做和 WebDAV 同步；PDF 原文件不会被改写。
- 新建的页间笔记保持空白时，在行首按退格会移除整个空笔记块；已有文字的页间笔记只删除当前空行，不会误删其他内容或 PDF。
- 整个笔记画布支持最高 600% 的双指几何缩放和平移：标题、Markdown 正文、图片、PDF 与页间笔记会作为同一张画布缩放，不改变原有排版和字号；文字在绘制阶段缩放，图片与 PDF 会按倍率加载更高分辨率预览。顶部操作栏和输入法上方的 Markdown 工具栏保持正常尺寸。缩小到适应宽度以下时，松手会回弹到适应宽度；双击仍只用于进入编辑，不会被缩放复位占用。
- 剪切、复制或删除 PDF 时，对应页间笔记会作为同一内容块一起移动、复制或删除，不会留下失效的隐藏数据。
- 长按图片、PDF 或附件会打开上下文操作：剪切、复制、删除；图片和 PDF 标题栏同时提供可访问的三点入口。
- 附件操作使用标准剪切、复制与粘贴逻辑：剪切会立即从原位置移除并写入系统剪贴板；随后在希望插入位置的正文、图片或 PDF 上长按并选择“粘贴”，即可放到该行之前，文末长按则粘贴到末尾。
- 文档末尾始终保留可操作的尾部空白区，即使最后一项是图片或 PDF，也能继续向下滚动并在文末粘贴；双击该区域会创建新的正文行。
- 尾部只提示“双击进入编辑模式”，不再展示多余的文末粘贴说明；编辑模式保留必要的键盘避让空间，但不显示提示文字。
- 删除仍会二次确认；只有在没有其他引用时才删除对应的内部文件。
- 其他文件显示为附件卡片。
- 所有文件都会复制到当前笔记的私有 `assets/` 目录；笔记不会依赖原文件 URI，也不会创建可点击的外部链接。

Mote 使用非链接的本地嵌入指令：

```markdown
![[asset:assets/uuid.png|照片]]
![[asset:assets/uuid.pdf|课程讲义]]
![[asset:assets/uuid.zip|资料包]]
```

旧版本写入的标准 Markdown 图片与本地 PDF 链接仍可正常预览。

## WebDAV 同步

主页侧边栏的“WebDAV 同步”打开独立设置页：

- 可以同时填写内网地址（HTTP/HTTPS）和外网地址（必须 HTTPS），共用账号、密码与远端目录；每次同步先用 3 秒连接超时尝试内网，失败后自动切换外网，不读取 Wi‑Fi 名称、位置或网络环境权限。
- 密码由 Android Keystore 的 AES-GCM 密钥加密后保存在本机；设置页禁止系统截图，日志不会记录密码或笔记正文。
- “保存并测试地址”会分别显示两个端点是否可用；“立即同步”在后台执行，不阻塞目录和编辑界面，并显示本次实际使用的端点及上传、下载、删除、冲突数量。
- Markdown、附件、嵌套文件夹和回收站会以原有 `files/notes/` 相对路径逐文件双向同步。路径经过规范化与根目录约束，WebDAV XML 禁止外部实体并限制响应体积。
- 空文件夹使用隐藏的 `.mote-folder` 占位文件同步；它不会显示在笔记库中，也不会进入 Markdown 正文。
- 同步使用上一次文件哈希与远端版本做三方判断。双方同时修改、或一方删除而另一方修改时，不静默覆盖：保留带“同步冲突”时间戳的本地副本；普通删除会同步到另一端，回收站仍可用于恢复。
- 首次同步遇到同路径但内容不同的文件时，本机版本保留在原路径，远端版本保存为冲突副本。建议第一次启用前先确认两端笔记均已备份。

当前版本提供手动同步，不会在后台定时联网；服务器证书使用 Android 系统信任链，不接受不受信任的自签名证书。

## 可热插拔插件平台

Mote 的插件是独立 APK，不会将任意 Android View、文件路径或编辑器对象注入主应用：

- 安装插件 APK 后，Mote 通过带 API 版本的 Binder Service 自动发现；卸载或更新会即时刷新，不需要重启 Mote。
- 没有安装插件时，编辑器插件入口隐藏，原有阅读、编辑、附件、PDF 和 WebDAV 链路不变。
- 首次运行会显示插件声明的能力，如读取整篇笔记、修改文本、调整文档结构、网络访问或语音输入；权限可在侧边栏的“插件管理”中撤销。
- 每个请求都有会话 ID、请求 ID 和文档版本指纹。笔记在插件运行期间被修改、请求取消、插件崩溃或被卸载时，旧结果会被丢弃。
- 插件只能返回候选 Markdown；Mote 验证附件与 PDF 页间标记、显示修改预览，用户确认后才以一次可撤销的结构编辑应用。

本 Release 同时提供独立的 **Mote AI Organizer** 示例插件。它支持 OpenAI Chat Completions 兼容接口，可分别配置内网和外网地址，并按顺序尝试；API Key 使用 Android Keystore 加密保存。提供“整理整篇笔记”、“生成摘要并整理”和“提取任务与行动项”，能生成多级标题、粗体、斜体、项目符号、编号和任务列表。插件未安装或未配置时，Mote 本体仍可完全离线使用。

不希望使用 AI 时，可以单独安装 **Mote 本地整理**。它不声明网络权限，以确定性规则在设备上规范标题、重点字段、项目符号、连续编号和任务项，也可生成去重的行动项清单。附件引用、PDF 页间标记和代码块会原样保留；结果同样必须经过 Mote 的修改预览后才能应用。

调用方式：安装插件 APK 后打开任意笔记，点击右上角拼图形“插件”图标，选择“Mote 本地整理”，再选择所需操作。首次调用确认能力授权，检查修改预览后点击“应用”；取消预览不会修改笔记，应用后的整次变更可以撤回。

插件协议、Manifest 声明、线程模型和安全约束见 [`docs/plugin-api.md`](docs/plugin-api.md)。

## 当前 MVP

- 行级混合 Markdown 编辑
- 多笔记、嵌套文件夹与笔记选择界面
- CommonMark、标题、强调、单行列表/引用、任务项和删除线渲染
- 图片、PDF 与普通附件的统一导入
- 文件复制到笔记私有目录，无存储权限；WebDAV 完全可选，未配置时保持离线
- 原子自动保存

## 本地数据结构

```text
files/notes/
├── .trash/
│   └── <回收站项目>/
│       ├── metadata.properties
│       └── payload/
├── welcome/
│   ├── note.md
│   └── assets/
└── 工作.folder/
    └── 计划.note/
        ├── .body-title-separated-v1
        ├── note.md
        └── assets/
```

`.folder` 与 `.note` 只用于内部区分类型，界面不会显示；旧版本没有后缀的笔记仍然兼容。
