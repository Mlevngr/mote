## Mote 0.9.0 · versionCode 59

- 新建笔记时可直接选择“导入 Markdown”，读取 `.md` / `.markdown` 文件并打开阅读模式。未填写名称时使用原文件名，也可先填写自定义名称；重名自动编号，不覆盖已有笔记。
- 导入保留正文标题、空行和 Markdown 格式，支持 UTF-8（可带 BOM）以及带 BOM 的 UTF-16。文件复制到当前文件夹下的笔记中，原文件不受修改；取消选择不会创建空笔记。
- 首页新增排序按钮，文件夹和笔记均可按名称或修改时间正序、倒序排列。时间正序为最早在前，倒序为最新在前；设置自动保存并应用到各层目录。
- 导入前检查扩展名、文本编码及 10 MB 大小上限，读取失败时给出提示。

### 安装与更新

主程序只需下载并安装 **Mote.apk**，两个 Organizer APK 为可选插件。

保持原包名和签名，支持覆盖更新已有固定测试签名版本，无需卸载应用。Obtainium 用户可继续使用 `^Mote\\.apk$` 过滤主程序更新。

单文件导入不会复制 Markdown 中相对路径引用的图片等外部资源。固定测试密钥公开，不具备生产私钥的安全性。
