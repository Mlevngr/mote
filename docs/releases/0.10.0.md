## Mote 0.10.0 · versionCode 60

- 新增“外观与布局 → 皮肤包与配色”，支持导入、导出 JSON 皮肤包，在应用内输入色值或选择预设颜色。
- 可分别编辑浅色、深色模式的页面背景、卡片与编辑区背景、正文、辅助文字、强调色与图标、边框和错误提示颜色；应用后跟随系统明暗模式切换。
- Markdown H1–H6 支持独立颜色，保留标题字号和粗体，代码块中的 `#` 不会被当作标题。笔记缩略图同步使用标题颜色。
- 提供实时预览。导入只载入编辑草稿，确认应用后生效；恢复内置主题可停用皮肤，同时保留已保存的配置。
- 附带 `docs/skins/warm-paper.json` 暖纸示例。皮肤文件为 UTF-8 JSON，最大 32 KB，颜色格式为不透明 `#RRGGBB`，不包含可执行代码。

### 安装与兼容

保留既有包名和固定测试签名，versionCode 从 59 增加至 60，支持覆盖更新。

完整界面配色需要 Android 11 或以上；Android 9–10 支持标题配色。无需额外插件 APK，也未新增项目依赖。

### 本地验证

已通过 262 项 JVM 单元测试、Android Lint、4 项皮肤模拟器集成测试及 5 项现有编辑器模拟器回归测试；签名和 APK 版本信息已核验。模拟器为 API 35，尚未在 Android 17 真机和 Android 9–10 设备验证。
